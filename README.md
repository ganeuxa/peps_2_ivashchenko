# Практическая работа №2 (ПР 3-4). Шина I²C в Proteus, вариант 14

Дисциплина «Программирование электронных приборов и систем», РТУ МИРЭА.
Выполнил Иващенко А.А., группа ЭФБО-07-24.

STM32F103C8 (I2C1: PB6 SCL, PB7 SDA, 100 кГц) работает ведущим на шине с EEPROM 24LC64 (адрес 0x50)
и часами DS1307 (адрес 0x68). Программа пишет байт 0x11 в ячейку 0x05FE, ждёт окончания записи
опросом ACK, читает байт обратно, затем выставляет время в DS1307 и читает регистр минут.
Если все шаги прошли, загорается светодиод на PA1.

## Сборка прошивки

Нужен Arm GNU Toolchain (arm-none-eabi-gcc). Путь к нему задаётся в начале `build.bat`.

```
cd "Прошивка STM32"
build.bat
```

Получится `lab2.elf`, он указан в свойстве Program File у STM32F103C8 в проекте Proteus.
